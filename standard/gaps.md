# gaps — เคสที่ gate เขียวแล้วยังพัง

**กติกา:** gate ผ่านแต่ของยังพัง → เติม 1 บรรทัดที่นี่ก่อนปิดงาน (AI เป็นคนเติม ทีมไม่ต้องจำ)

ไฟล์นี้คือ**ตัวนับหลักฐาน** ที่ใช้ตัดสินว่าจะเปิดเครื่องมือที่เลื่อนไว้เมื่อไหร่
ถ้าไม่มีที่จด ครั้งที่ 1 กับครั้งที่ 2 จะไม่มีวันถูกนับต่อกัน แล้ว "เลื่อนไว้" จะกลายเป็น "ตัดทิ้ง" โดยปริยาย

รูปแบบ: `วันที่ | หมวด | อาการ | ที่เกิด`

หมวดที่ใช้: `dup` (logic ซ้ำ) · `string-key` (typo ใน rpc/flag/event/route) · `perf` · `seam` (coupling ข้ามขอบเขต) · `other`

## นับตอนนี้

| หมวด | จำนวน | เปิดใช้เมื่อ |
|---|---|---|
| dup | 0 | ถึง 2 → เปิด clone detector |
| string-key | 0 | ถึง 1 → เปิด const registry + lint rule |
| seam | 0 | ถึง 1 → เริ่มออกแบบ contract รอยต่อโมดูล (R4) |
| perf | — | **ไม่รอให้พัง** ดู v1.md — perf ต้องวัดก่อนส่งมอบ |
